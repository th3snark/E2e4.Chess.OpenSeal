# Security policy

This library encodes the timeseal/openseal handshake for FICS connections, so reports are welcome.

Please report a vulnerability privately through GitHub: **Security > Report a vulnerability** on
<https://github.com/th3snark/E2e4.Chess.OpenSeal>. Do not open a public issue for it. Include the version, the input that
triggers it and a minimal reproduction. You can expect an acknowledgement within a few days.

In scope: crashes, hangs, out-of-range access or unbounded memory use on crafted input, and memory-safety problems in the native component. Out of scope: anything that needs a modified build.
